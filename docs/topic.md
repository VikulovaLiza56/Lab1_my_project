# Разработка веб-сайта (указать наименование) на базе фреймворка Flask.

## Название
Приложение анализатор погодных данных

## Краткое описание
Консольное, затем веб-приложение для учёта личных доходов
и расходов: ввод операций, категории, отчёты по периодам.

## Целевой пользователь
Студент/сотрудник, желающий контролировать личный бюджет.

## Базовые функции (минимум для зачёта)
1. Добавление операции (доход/расход, сумма, дата, категория)
2. Просмотр списка операций
3. Удаление и редактирование операции
4. Итог за период (баланс)

## Возможные расширения
Поиск по описанию, категории с лимитами, экспорт в CSV,
веб-интерфейс с графиками.
