## Приложение анализатор погодных данных

Цель проекта: разработка веб-сервиса на Flask для сбора, накопления и анализа метеоданных по Иркутску и окресностям.

## Возможности

### Сбор данных
- **Опрос METAR/TAF** аэропорта Иркутск (UIII) каждые 30 минут по расписанию APScheduler.
- **Разовая выгрузка исторического архива** за 10–15 лет (meteostat / Open-Meteo Historical API).
- **Опциональный народный мониторинг** — опрос публичных датчиков по районам Иркутска каждые 15 минут (учитывает микроклимат).

### Аналитика
- **Барическая тенденция** — изменение давления за последние 3 часа (маркер приближения фронтов и усиления ветра).
- **Климатическая аномалия** — отклонение текущей температуры от средней исторической нормы для текущего дня.
- **Риск заморозка** — эвристика: вечер + ясно + ветер < 2 м/с + точка росы ≤ 0 °C.
- **Градусо-сутки отопления (HDD)** — суточный подсчёт для оценки нагрузки на отопление.

### Веб-интерфейс
- Страница статуса: последнее обновление, текущие параметры.
- Дашборд с графиками Chart.js:
  - суточный ход температуры и давления;
  - роза ветров / распределение направлений за неделю;
  - «факт vs историческая норма».
- Таблица архива с фильтром по датам и экспортом в CSV.
