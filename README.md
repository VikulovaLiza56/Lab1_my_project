## Мой проект: ЧТО и КАК

**ЧТО** (анализ): какие задачи пользователя решает система
- Собрать и сохранить исторический архив и актуальные метеоданные по Иркутску (аэропорт UIII).
- Рассчитать вычисляемые климатические метрики (барическая тенденция, градусо-сутки для отопления, угроза заморозков).
- Предоставить REST API для автоматического опроса и интеграции данных в систему умного дома (Home Assistant).

**КАК** (проектирование): предполагаемые решения
- хранение: SQLite (на старте) → PostgreSQL · интерфейс: REST API (JSON) + дашборд (Chart.js)
- архитектура: Python 3.11+, Flask для API, SQLAlchemy для ORM, APScheduler для фонового сбора сводок METAR.
